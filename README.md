# Huispedia skills for Claude Code

Skills for the [Huispedia Data Intelligence API](https://huispedia.dev): Dutch property data by address.

- `huispedia-api`: keys, locators, endpoints, credits, rate limits and errors.
- `migrate-from-altum`: move an integration from Altum to Huispedia.
- `migrate-from-matrixian`: move an integration from Matrixian to Huispedia.

## Install

```
/plugin marketplace add Housepedia/claude-plugins
/plugin install huispedia-api@huispedia
```

More on https://huispedia.dev/en/docs/claude/. This repository is generated from the docs on every release; changes go through Huispedia.
